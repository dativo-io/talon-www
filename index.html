What changed in the coding-agent work

Governance that follows the session across providers.

The coding-agent epic adds a neutral orchestration contract and session-level proof without teaching Talon how to spawn, schedule, or reason about agents.

Attribution

Neutral orchestration metadata

Generic X-Talon-* headers plus vendor mappings for Claude Code and Codex. Identity is client-asserted attribution, never authentication or a policy input.

Metadata contract →
FinOps

Cache-aware provider cost

Anthropic cache creation/read and OpenAI cached input are priced correctly, including streamed Responses usage. Evidence records the pricing basis.

Session cost →
Control

Session soft caps

New requests are denied once accumulated session spend plus the pre-request estimate exceeds the limit, even across provider routes. In-flight concurrency can still overshoot.

Budget semantics →

Governed resilience

Outages do not get a policy exception.

On a transient provider failure, Talon can walk an ordered fallback chain. Every candidate is checked against provider and model allowlists, tool policy, budgets, session context, and sovereignty. Under eu_strict, a non-EU/LOCAL candidate is skipped rather than silently used.
