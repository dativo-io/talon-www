How it works

Policy before provider access. Evidence after every decision.

Talon is not a dashboard you check after the damage is done. It sits on the request path and records allowed, denied, redacted, filtered, and failed requests as audit evidence.

Fast integration

Start with one base URL change.

Your application can keep using the same OpenAI-compatible SDK. Point the base URL at Talon, send a Talon caller key, and let Talon inject the approved provider credential from its vault.

Existing app Slack bot OpenClaw Vendor AI 
# Before
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_API_KEY=sk-provider-key

# After
OPENAI_BASE_URL=http://talon:8080/v1/proxy/openai/v1
OPENAI_API_KEY=<talon-caller-key>

# Then inspect proof
talon audit list
talon audit verify <evidence-id>
