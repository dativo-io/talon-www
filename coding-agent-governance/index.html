The control point

One gateway for two wire families.

Talon proxies Anthropic Messages traffic and OpenAI Responses traffic without becoming the orchestrator. Claude Code, Codex CLI, or a custom coordinator keep deciding what work happens; Talon decides whether provider-bound traffic may proceed and records what happened.

Neutral contract

The role names belong to your fleet, not Talon.

Orchestrator, planner, generator, reviewer, and executor are examples only. Agent, parent-agent, and client values are free-form attribution labels. Talon never authenticates them or uses them as policy inputs. The only fixed stage vocabulary is generation, judge, or commit.

Spend control

Stop the next request when a coding session crosses its budget.

max_session_cost is a caller-scoped soft cap. A new request is denied once accumulated spend plus the pre-request estimate exceeds the limit, even when the session moved between provider routes. The denial uses the provider's native error shape and carries structured signed evidence.

Session-budget semanticsCaller budgets
policy_overrides:
  max_session_cost: 10.00
  max_daily_cost: 50.00
  max_monthly_cost: 500.00

Agentic traffic coverage

More of the coding loop is visible — with explicit limits.

Talon covers wire-level details that matter for real coding clients without pretending it can see local execution.

Responses instructions are governed

The Responses API instructions field is treated as prompt text, so PII there is scanned and can be redacted.

Tool-related request content is evidenced

Tool-use inputs, tool-result outputs, and function-call arguments are scanned into signed tool_content evidence. This signal is evidence-only today: Talon does not redact or block on it yet.

Local execution is still outside the gateway

Files edited, commands run, and tools executed locally remain invisible when those actions never cross Talon. Model tool-use intentions are not execution proof.

Protocol fidelity

The governance path fits long-running coding clients more honestly.

Retention intent preserved

responses_store_mode: preserve is the default, so explicit client store:false is not silently reversed. Force modes are explicit operator choices.

Long TTFB no longer dies at 10 seconds

connect_timeout bounds connection establishment. Response-header wait defaults to request_timeout, which the coding pack raises to 600 seconds.

Backoff and free token-count calls stay truthful

Retry/rate-limit headers reach clients, while Anthropic count_tokens remains fully governed but records zero cost and zero budget impact.

Multi-tenant deployments

Scope CLI-set provider secrets when customers share a gateway.

Repeatable --tenant and --agent ACL flags on talon secrets set scope provider secrets to the intended tenants or agents. The backward-compatible default remains allow-all and prints a warning.

Honest boundaries

What Talon does not govern.

Local tool execution

File edits, shell commands, and local tool runs that never cross Talon are invisible.

Subscription/OAuth billing

Governed Claude Code and Codex operation requires a Talon caller key in and a vault-stored provider API key out.

Hard reservation

Session budgets are soft caps. Atomic reservation for strict concurrent hard caps remains separate work.
