The control point

One gateway for two wire families.

Talon proxies Anthropic Messages traffic and OpenAI Responses traffic without becoming the orchestrator. Claude Code, Codex CLI, or a custom coordinator keep deciding what work happens; Talon decides whether provider-bound traffic may proceed and records what happened.

🧩

Neutral orchestration metadata

Generic X-Talon-* headers work on every route. Built-in vendor mappings recognize Claude Code and Codex headers without client-specific branches in the governance core.

💶

Correct coding-agent spend

Usage and cost account for Anthropic cache creation/read tokens and OpenAI cached input, including streamed Responses traffic. Evidence records whether pricing came from the table or a fallback basis.

🔏

Session evidence

List, export, cost, and verify one session across providers. One aggregation powers the CLI and dashboard so the two surfaces cannot drift.

Neutral contract

Any orchestrator can participate without Talon learning its vocabulary.

The client chooses the labels. Talon records session, agent, parent-agent, client, and optional stage metadata. Agent identity is attribution only: it is client-asserted, never an authentication claim and never a policy input. Budgets bind to the authenticated caller and caller-scoped session.

Spend control

Stop the next request when a coding session crosses its budget.

max_session_cost is a caller-scoped soft cap. A new request is denied once accumulated spend plus the pre-request estimate exceeds the configured limit, even when the session moved from one provider route to another. The denial is rendered in the provider's native error shape and carries structured signed evidence.

Honest boundaries

What Talon does not govern.

The gateway sees model API traffic. It does not become an endpoint security product or an agent runtime.

Local tool execution

File edits, shell commands, and local tool runs that never cross Talon are invisible. Evidence can show model tool-use intentions, not execution on a developer machine.

Subscription/OAuth billing

Governed Claude Code and Codex operation requires a Talon caller key in and a vault-stored provider API key out. Subscription login traffic cannot be governed as spend.

Hard reservation

Session budgets are soft caps. Atomic reservation for strict concurrent hard caps remains separate work.
