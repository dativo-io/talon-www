Why add a control plane

The second and third AI use cases should not rebuild the same controls.

LangGraph gives the application a strong agent runtime. Talon addresses the cross-use-case operating problem: common spend rules, provider/model/data/tool policy, provider-path evidence and session history on traffic that crosses Talon.

Cost

Apply per-request and caller controls before provider access; use asserted-session cost views where supported.

Policy

Apply model/provider, PII, tool-schema and regional rules outside the individual graph implementation.

History

Inspect signed decisions and asserted-session evidence without turning application logs into the sole source of truth.

Minimal setup

Point the LangGraph model client at Talon.

The first integration path is the LLM API gateway. Keep the LangGraph graph and application logic; change the supported provider client base URL and use a Talon caller key.

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4o-mini",
    base_url="http://localhost:8080/v1/proxy/openai/v1",
    api_key="<talon-caller-key>",
)

# Use llm inside LangGraph nodes as usual.

Boundary

Talon governs the path, not the whole graph.

Model requests routed through Talon can be controlled and evidenced. Tool schemas visible to the gateway can be filtered. Local Python actions, direct APIs and tool execution that bypass Talon remain outside its view.

LangGraph activityTalon visibility
Model API request routed through TalonGoverned and evidenced.
Tool schema included in governed LLM requestCan be filtered/blocked by supported gateway policy.
MCP/tool call routed through Talon interceptionCan be governed on supported path.
Local node code, shell command or direct API bypassInvisible and uncontrolled by Talon.

Verify

Inspect the use case after a run.

Use current CLI surfaces to review recent evidence, explain one decision, verify integrity and inspect cost.

talon audit list --limit 10

talon audit show <evidence-id>

talon audit verify <evidence-id>

talon costs --agent <name>
