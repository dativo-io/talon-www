What gets recorded

Compact records for the decisions that matter.

Talon evidence is designed for incident review, customer security questions, coding-agent rollouts, and auditor handoff — not just dashboard charts.

🧾

Decision context

Caller, tenant, policy version, allow/deny/redact decision, reason, runtime path, and session budget detail when applicable.

🧑‍💻

Orchestration context

Session id, agent id, parent-agent id, client label, stage, and provenance for client-asserted coding-agent attribution.

💶

Cost context

Input/output/cache tokens, provider-aware amount, pricing basis, and whether the pricing entry was known.

Coding-session evidence

Audit the whole multi-model session as one unit.

A caller-scoped session can span Anthropic and OpenAI routes. Talon aggregates requests, providers, models, tokens, cost, denials, and per-subagent attribution from signed evidence. The same pure aggregation powers the CLI and Coding Sessions dashboard.

Provider failover evidence

Show that reliability did not bypass governance.

When a transient provider failure engages a fallback chain, Talon writes one signed attempt record per failed provider and exactly one terminal record for the selected fallback or the fail-closed result. Candidate policy skips are distinct from runtime failures.
