Sovereignty posture report

Turn evidence into a reviewable data-residency artifact.

The sovereignty report combines declared config — routing mode, deployment mode, gateway providers, and allowed egress — with runtime evidence such as observed destinations, egress denials, and routing rejections. It is supporting evidence, not a legal determination.

Report overviewAir-gap guideExport runbook
talon compliance sovereignty \
  --format json \
  --tenant acme \
  --gateway-config talon.config.yaml \
  --output sovereignty.acme.json

talon compliance sovereignty \
  --format html \
  --output sovereignty.acme.html

Review workflow

Export, sample, verify, explain posture.

For a customer, DPO, security, or auditor review: export a period, sample evidence IDs, verify signatures, and attach the sovereignty posture report to show configured controls and observed runtime destinations.
