Why buyers care

Security reviews ask for proof, not intent.

A policy document saying “we prefer EU providers” is not enough when AI traffic touches customer, employee, financial, health, or regulated operational data. Talon gives teams a concrete artifact that ties configuration to observed runtime behavior.

Air-gap mode

For local-only or private in-region model deployments.

Air-gap mode forces eu_strict posture, requires explicit crypto keys, applies deny-by-default EU/LOCAL egress when no custom gateway egress policy exists, and wraps upstream HTTP with an allowlist derived from local Ollama, declared gateway providers, optional allowed hosts, and loopback.

Air-gap deployment guideConfiguration referenceProvider registry
sovereignty:
  mode: eu_strict
  deployment_mode: air_gap

gateway:
  providers:
    ollama:
      enabled: true
      base_url: http://127.0.0.1:11434
      region: LOCAL

talon doctor --gateway-config talon.config.yaml

Customer-safe language

Supporting evidence, not a compliance certificate.

The report helps teams answer practical review questions: which providers were configured, which destinations were observed, what was blocked, and which records verify. It does not replace legal advice, a DPO assessment, or a formal compliance certification.

# Generate JSON for machines

 talon compliance sovereignty --format html \
   --output sovereignty.html
